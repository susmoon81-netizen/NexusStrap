Install in a minute

1

Install the .NET 10 Desktop Runtime if Windows asks for it.

2

Download NexusStrap.exe from the Releases page.

3

Run it. It installs Roblox and opens settings on first launch.

Requires Windows 10 (1903+) or Windows 11, 64-bit. The download is small because the .NET runtime is not bundled.

FAQ

Is this affiliated with Roblox?

No. Unofficial community project. Roblox is a trademark of Roblox Corporation.

My antivirus flagged it. Is it safe?

Launchers like this get false-flagged because they download and manage game files. This site ships source code openly — read it, build it yourself, and only run copies from the official Releases page.

Does it need my password or cookie?

No. It never asks for your Roblox password. Never share your .ROBLOSECURITY cookie with anyone.

Where do I get help?

Join the Discord or open an issue on GitHub.
